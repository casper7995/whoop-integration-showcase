# WHOOP Integration Showcase

Static demonstration page for [EnduranceCoach AI](https://endurancecoaching.ai), showing how WHOOP recovery, HRV, sleep, and strain metrics could inform AI-powered training adaptations.

**Live demo:** [casper7995.github.io/whoop-integration-showcase](https://casper7995.github.io/whoop-integration-showcase/)

## Purpose

This repository hosts a single-page showcase of the intended WHOOP integration experience: account connection, readiness dashboard, and AI coach recommendations that adjust training intensity based on recovery data.

All metrics on the demo page are illustrative. No live WHOOP data is collected from this static site.

## What it shows

1. **Mock OAuth flow** — example WHOOP account connection experience
2. **Recovery dashboard** — recovery score, HRV, sleep, and strain at a glance
3. **AI coach recommendations** — example training adaptation based on readiness trends
4. **Integration workflow** — connect, analyze, adapt, and optimize

## Related project

The main product is [EnduranceCoach AI](https://endurancecoaching.ai), an AI-powered endurance coaching platform with Garmin integration, adaptive training plans, and a conversational AI coach. WHOOP integration extends readiness monitoring for athletes on the platform.
